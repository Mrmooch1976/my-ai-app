# Personal AI Assistant

A command-line AI toolkit for managing daily nutrition, fitness, and budgets.

## How to Run

1. Navigate to the **Releases** tab on the right side of this GitHub repository.
2. Download the latest version of the `app` binary file from the Assets section.
3. Open your terminal, set your OpenAI API key, and execute the file:

```bash
export OPENAI_API_KEY="your-api-key-here"
chmod +x app
./app
```
